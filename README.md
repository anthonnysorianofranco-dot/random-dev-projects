## 🔄 El Flujo de Trabajo Básico

Si eres nuevo en Git, recuerda esta secuencia simple:

1. `git pull`
   ↓
2. Trabaja en tu proyecto
   ↓
3. `git status`
   ↓
4. `git add .`
   ↓
5. `git commit -m "describe tus cambios"`
   ↓
6. `git push`

En resumen:

`bash`
git pull

# Trabaja en tu proyecto

git status
git add .
git commit -m "feat: agregar mi proyecto"
git push

`markdown`

## ⚠️ Reglas Importantes

- **No trabajes directamente en el proyecto de alguien más:** Si quieres modificar el proyecto de otra persona, pregúntale primero.
- **Mantén tu proyecto dentro de su propia carpeta:** No mezcles archivos de diferentes proyectos.
- **No subas archivos innecesarios:** Evita hacer commit de carpetas como `node_modules/`, `.vscode/`, `bin/`, `obj/` o `.env`.
- **No subas contraseñas ni claves de API:** Nunca subas claves de API, contraseñas, tokens o credenciales de base de datos.

## 🧑‍💻 Para Alguien Completamente Nuevo en Git

Si nunca has usado Git, estos son los comandos principales que necesitas:

`bash`

# Entrar al repositorio

cd random-dev-projects

# Obtener los últimos cambios

git pull

# Ver qué cambió

git status

# Preparar cambios

git add .

# Guardar cambios

git commit -m "tu mensaje"

# Subir cambios

git push
